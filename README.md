# ระบบลงพิกัดบ่อเลี้ยงปลา & ฐานข้อมูลเกษตรกร (Fish Farm GIS & Management)

ระบบสารสนเทศภูมิศาสตร์และฐานข้อมูลผู้เพาะเลี้ยงสัตว์น้ำ (ปลานิล, ปลาดุก, ปลากะพง, ปลาสลิด ฯลฯ) พร้อมระบบระบุพิกัด GPS แสดงผลบนแผนที่ดาวเทียม Google Map และ OpenStreetMap รวมถึงการจัดเก็บประวัติเกษตรกร อัปโหลดรูปภาพบ่อเลี้ยง และแนบเอกสารสิทธิ์/ใบรับรองมาตรฐาน GAP

---

## 🌟 คุณสมบัติเด่น (Features)

1. **ระบบพิกัดและแผนที่ (GIS & Google Maps Integration)**
   - **ระบบจำกัดขอบเขตระดับจังหวัดและอำเภอ (Province & District Scoping):** สามารถเลือกกำหนดจังหวัดและอำเภอปฏิบัติงานได้จากแถบด้านบน (รองรับทั้ง 77 จังหวัด และ 928 อำเภอทั่วไทย)
   - **เส้นขอบเขตอาณาเขตตรงตามมาตรฐานกรมการปกครอง (Official DOPA Boundaries):** ปรับปรุงเส้นอาณาเขตจังหวัดและอำเภอให้ตรงกับเส้นประ (จุดไข่ปลา) บนแผนที่ดาวเทียม Google Maps อย่างแม่นยำ 100%
   - **ระบบแสดงเส้นแบ่งเขตระดับอำเภอ (District Boundaries Layer):** แสดงเส้นแบ่งเขตอำเภอพร้อมป้ายชื่ออำเภอภาษาไทย/อังกฤษ คลิกที่อำเภอใดเพื่อซูมและกรองข้อมูลเฉพาะอำเภอนั้นได้ทันที
   - **ปุ่มเปิด/ปิดเส้นเขต:** สามารถเลือกเปิด/ปิดเส้นอาณาเขตจังหวัด และเส้นแบ่งเขตอำเภอแยกอิสระได้
   - **ระบบป้องกันการลงพิกัดข้ามเขต (Boundary Guard):** แจ้งเตือนอัตโนมัติหากมีการจิ้มพิกัดห่างไกลนอกพื้นที่จังหวัดที่กำลังปฏิบัติงาน
   - **ระบบค้นหาสถานที่เจาะจงจังหวัด:** ค้นหาตำบล/อำเภอโดยระบบจะค้นหาเฉพาะในจังหวัดที่เลือกเท่านั้น ไม่กระโดดข้ามไปจังหวัดอื่น
   - **แสดงแผนที่ดาวเทียมความละเอียดสูง:** Google Maps Satellite, Google Hybrid (ดาวเทียม+ชื่อถนน) และ OpenStreetMap
   - **ปักหมุดระบุพิกัด (Latitude, Longitude) ได้ 3 รูปแบบ:**
     1. จิ้มเลือกตำแหน่งโดยตรงบนแผนที่ (Interactive Pinning)
     2. ดึงพิกัดปัจจุบันผ่านดาวเทียม GPS จากมือถือหรือคอมพิวเตอร์ (One-click Geolocation)
     3. กรอกตัวเลขพิกัด WGS84 ด้วยตนเอง
   - ปุ่ม **"เปิดใน Google Maps"** สำหรับนำทางตรงด้วย Google Maps Application บนมือถือทันที

2. **ฐานข้อมูลเกษตรกรผู้เพาะเลี้ยงสัตว์น้ำ (Farmer Database)**
   - จัดเก็บข้อมูลเกษตรกร: ชื่อ-นามสกุล, เลขประจำตัวเกษตรกร (ทบก.) / เลขบัตร ปชช., เบอร์โทรศัพท์, ที่อยู่, ตำบล, อำเภอ, จังหวัด และหมายเหตุ
   - 1 เกษตรกรสามารถมีบ่อเลี้ยงปลาได้หลายบ่อ (One-to-Many Relationship)
   - ค้นหา กรอง และแก้ไขข้อมูลเกษตรกรได้อย่างสะดวกรวดเร็ว

3. **ข้อมูลรายละเอียดบ่อเลี้ยงปลา (Fish Pond Profiles)**
   - ชื่อบ่อ / รหัสแปลง
   - ชนิดปลาที่เลี้ยง (ปลานิลจิตรลดา, ปลาดุกบิ๊กอุย, ปลากะพงขาว, ปลาสลิด, ปลากดคัง ฯลฯ)
   - ขนาดพื้นที่ (ไร่ - งาน - ตารางวา) และความลึกของบ่อ (เมตร)
   - ปริมาณปลาที่ปล่อย (ตัว), วันที่ปล่อย, วันที่คาดว่าจะเก็บเกี่ยวผลผลิต
   - แหล่งน้ำที่ใช้ (คลองชลประทาน, น้ำบาดาล, น้ำฝน ฯลฯ)
   - สถานะบ่อ (กำลังเลี้ยง, เตรียมบ่อ, เก็บเกี่ยวแล้ว, พักบ่อ)
   - บันทึกผลตรวจค่าน้ำและหมายเหตุ

4. **ระบบอัปโหลดรูปภาพ (Photo Gallery & Preview)**
   - อัปโหลดรูปภาพสภาพบ่อปลา, ภาพปลา, การให้อาหาร
   - แสดงแกลเลอรีภาพขนาดเล็ก (Thumbnail) บนการ์ดและป๊อปอัปแผนที่
   - ระบบขยายดูรูปภาพขนาดใหญ่ (Lightbox Preview)
   - ระบุคำอธิบายภาพและวันที่อัปโหลด

5. **ระบบแนบเอกสาร (Document Attachments)**
   - แนบเอกสารสิทธิ์ที่ดิน (โฉนด / นส.3ก / สปก. 4-01)
   - แนบใบรับรองมาตรฐานการเพาะเลี้ยงสัตว์น้ำที่ดี (GAP)
   - แนบใบกำกับการเคลื่อนย้ายสัตว์น้ำ (MDD) หรือผลตรวจวิเคราะห์ค่าน้ำ
   - รองรับไฟล์ PDF, Word, Excel, รูปภาพ พร้อมระบบดาวน์โหลดคลิกเดียว

6. **ระบบรายงานและส่งออกข้อมูล (Export & Report)**
   - สรุปตัวเลข Dashboard: เกษตรกรรวม, บ่อปลาทั้งหมด, กำลังเลี้ยง, เนื้อที่รวม (ไร่), ลูกปลารวม
   - ส่งออกข้อมูลเป็นไฟล์ Excel / CSV รองรับภาษาไทย (UTF-8 with BOM)
   - รองรับการสั่งพิมพ์รายงาน (Print-friendly format)

## 🚀 วิธีการติดตั้งและเริ่มใช้งาน

### 1. เรียกใช้งานได้ทันที (1-Click Run)
ดับเบิลคลิกที่ไฟล์:
```
run.bat
```
ระบบจะเปิดเว็บเบราว์เซอร์อัตโนมัติไปที่: **`http://127.0.0.1:8000`**

### 2. รันผ่าน Command Line
```powershell
cd fish_farm_tracker
python app.py
```
